# Training data

Drop the two sets of images here — that's it, no need to rename anything up front.

- `headshots/` — the original photos
- `avatars/` — the hand-drawn VCCP avatars

## How to add files

1. Open this folder on GitHub (`data/headshots` or `data/avatars`).
2. Click **Add file → Upload files**.
3. Drag and drop the images in, then commit straight to this branch (`claude/photo-avatar-automation-8cx27y`).

You can upload in batches — no need to do it all in one go.

## Notes

- Any common image format is fine (jpg, png, heic, webp).
- Filenames don't need to match between the two folders — we'll pair each headshot with its avatar using a separate matching tool, since the artwork is stylized and can't be auto-matched by filename or face recognition.
- Please don't include any photos of people who haven't consented to being used as training data for this.
